Rumus Geser bit 

Contoh:
1. 2020 >> 2
2. 2^2 (geser 2 kali ini menjadi pangkat 2, jika geser 3x maka 2^3)
3. 2^2 = 4
4. 2020 / 4 jika geser bit nya ke kiri maka 2020 * 4
5. 2020 / 4 = 505
2020 >> 2 = 505
